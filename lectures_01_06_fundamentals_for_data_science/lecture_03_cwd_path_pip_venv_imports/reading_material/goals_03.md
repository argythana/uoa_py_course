# Lecture 03: CWD, Path, pip, venv, Imports

## Learning Goals

### Python

- Use basic CLI commands (`cd`, `ls`/`dir`, `mkdir`, `pwd`) to navigate the file system.
- Understand absolute vs relative paths and the concept of current working directory (CWD).
- Create and activate Python virtual environments (`venv`); install packages with `pip`.
- Set up and use JupyterLab for interactive Python development.
- Import built-in modules (`math`, `random`, `statistics`); use dot notation, `from ... import`, and aliases.

### Agents

- context window and agent performance
- the agent commnads that start with `/`, examples: `/clear`, `/savePrompt`
- adding files as context
