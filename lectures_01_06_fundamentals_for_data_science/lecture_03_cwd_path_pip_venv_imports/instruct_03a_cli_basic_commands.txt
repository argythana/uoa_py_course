	-------------------------
	How to open the terminal:
	-------------------------

    The "Terminal" is also known as "Command Prompt", "Console", "Command Line Interface" (CLI), "Shell".
    I will refer to it as **CLI** or **terminal**.

    In Windows:
	a) press `Windows key` + `R`
	b) type the word `cmd`, press Enter

    You should now be inside the **Operating System** terminal in **your user** default path:
    `C:\Users\thanasis_argyriou>`

    "thanasis_argyriou" is me, not you!

    Or, in Windows 11:
    a) press `Windows key`,
    b) start typing `command prompt`,
    c) press `Enter` when you see the `Command Prompt` App.

    IMPORTANT: Each modern python Editor has its terminal. We mostly use that terminal.


    -------------------
    Basic CLI commands:
    -------------------
	
	1. `dir` => list the files and folders in current directory (from the word directory).
	* the equivalent command in Mac is `ls`  (list).
	
	2. `cd` => change directory

	3. `mkdir` => make a new directory (folder)

    Examples and practice:
	1. Open the Windows terminal.

	2. Type `dir` and press `enter`. (Without quotes).

	3. Type `mkdir uoa_py_course` and press `enter`.

	4. Type `cd uoa_course` and press Enter. You have moved to:

	5. Type `mkdir lectures` and press `enter`.

	5. Type `cd ..` and press `enter` => go "up" one folder.

	6. Type `cd uoa_course\lectures` => you change directory to two folders "down".

	7. `cd ..\..` => you change directory and move two folders "up".


	------------------------------------------------
	Move from terminal to graphics Windows and back.
	------------------------------------------------

	If you type `cmd` in any window's search bar, it will open the terminal in that path.

	If you type `start.` in the terminal, it will open a window in that path.

	If you type `start` in the terminal, it will open another terminal in that path.
