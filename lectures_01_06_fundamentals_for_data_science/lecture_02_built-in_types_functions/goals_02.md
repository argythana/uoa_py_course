# Lecture 02: Built-in Types & Functions

## Learning Goals

### Python

- Understand numeric data types (integer, float), variable assignments, and the `type()` function.
- Perform basic numeric operations (+, -, *, /, //, %, **, `divmod()`).
- Create strings, use escape characters (`\`, `\n`), concatenation (`+`), and multiplication (`*`).
- Identify and use Python built-in functions: `print()`, `type()`, `int()`, `float()`, `str()`, `len()`, `abs()`, `pow()`, `range()`, `input()`.
- Distinguish between function parameters (names) and arguments (values); identify positional, keyword, optional, and required arguments.
