# Lecture 1 Exercises (Python)

Use the Python interpreter for quick tests and IDLE for script runs.

## A. Warm‑up (Interpreter)

1. Start the interpreter and print a greeting that includes your name.
2. Use help() on print. In one sentence, describe what the parameter "sep" does.
3. Create a variable called x with value 7. Print x.
4. Create variables a = 3 and b = 5. Print a + b, a - b, a * b.

## B. Print practice (Script)

1. Create a script and print three numbers in one line separated by commas.
2. Print the same three numbers on one line separated by " | ".
3. Print a line without going to the next line, then print another word on the same line.

## C. Names and errors

1. Which of these are valid names? If invalid, explain why.
   - 1item
   - item_1
   - Item
   - total-cost
   - total_cost
2. Write two different variable names that refer to different values but differ only by case.
3. Create a NameError intentionally, then fix it.

## D. PEMDAS and readability

1. Predict the result, then verify in the interpreter:
   - 20 / 5 / 4
   - 20 / (5 / 4)
2. Rewrite this expression with readable spacing and minimal parentheses:
   - 2*a+4*3+A/4*5
3. Add parentheses to force a different result in part (2).

## E. Comments and docstrings

1. Add a single‑line comment describing a calculation.
2. Add a module docstring at the top of your script describing what it does.

## F. Mini‑project (Café order)

Create a script that:

1. Defines prices and quantities for at least three items.
2. Computes a subtotal and a 10% discount.
3. Prints a clean receipt with item totals, subtotal, discount, and final total.

## G. Challenge

1. Add a tax rate (e.g., 24%) after the discount. Print the final price.
2. Make the receipt print one line per item using a single print() call per line.

## H. Reflection (short answers)

1. What is the difference between interactive output and script output?
2. Why is readability important in code?
