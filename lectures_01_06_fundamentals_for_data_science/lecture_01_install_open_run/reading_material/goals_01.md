# Lecture 01: Install, Open, Run

## Learning Goals

### Python

- Use `print()` output and its parameters (`sep`, `end`).
- Do some simple assignments: `name = value`.
- Perform basic arithmetic operations.
- Recognize valid/invalid Python syntax, comments (`#`), and docstrings (`"""`).
- Understand common Python errors (IndentationError, SyntaxError, NameError) and PEMDAS operator precedence.

### Agents

- Add GitHub Copilot and student's developer pack in IDE
- Select model
- Agent versions, updated models versus updated python modules
- Knowledge cut-off date
- Non-deterministic output
- Demo 'Ask', 'Plan', 'Edit' modes
- Discuss: hallucinations, AI slop, muscle and brain atrophy
- Discuss: clear communication as a top skill
- Human - AI interaction
