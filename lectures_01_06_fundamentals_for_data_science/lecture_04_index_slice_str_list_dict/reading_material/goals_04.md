# Lecture 04: Index, Slice, Strings, Lists, Dicts

## Learning Goals

- Understand indexing and slicing on ordered iterables (strings, lists).
- Distinguish mutable (lists) vs immutable (strings, tuples) data types.
- Use basic string methods and functions (`len()`, `replace()`, `split()`).
- Create and manipulate lists, tuples, and sets; understand their properties.
- Create and use dictionaries as key-value pair containers; use dict methods.
