# Lecture 05: Boolean, Conditions, Control Statements

## Learning Goals

- Understand truth value testing and the `bool()` function; `True`/`False` constants.
- Use comparison operators (`<, <=, >, >=, ==, !=, is, is not`) and boolean operations (`and`, `or`, `not`).
- Write `while` loops with `break`, `continue`, `pass` inner statements.
- Write `if/elif/else` conditional statements; understand pseudocoding as a prerequisite skill.
- Write `for` loops using `range()` and iteration over sequences; understand indentation and statement ordering.

## Files

- `lec_05a_boolean.ipynb` — Boolean operations, comparisons, identity, membership tests (`in`).
- `lec_05b_while_loop.ipynb` — `while` loop syntax, `break`/`continue`/`pass`, Fibonacci example.
- `lec_05c_if_condition.ipynb` — `if/elif/else` conditionals, nested conditions, pseudocoding.
- `lec_05d_for_loop.ipynb` — `for` loops with `range()`, iterating over sequences, nested loops.
