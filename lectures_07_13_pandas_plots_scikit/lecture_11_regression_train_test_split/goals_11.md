# Lecture 11: Regression & Train/Test Split

## Learning Goals

- Implement simple univariate linear regression using statsmodels OLS.
- Implement multiple linear regression with statsmodels and pingouin.
- Understand model fitting, overfitting vs underfitting, bias-variance tradeoff.
- Interpret linear model coefficients and their pitfalls (conditional vs marginal dependence).
- Split data into train/test sets for model evaluation.

## Files

- `lec_11a_simple_lin_regression.ipynb` — Simple linear regression using statsmodels on temp-to-coffee data.
- `lec_11b_multiple_lin_regr_draft.ipynb` — Multiple regression with pingouin and statsmodels; overfitting.
- `lec_11c_advanced_linear_model_coeff_interpretation.ipynb` — Advanced: pitfalls of coefficient interpretation.
