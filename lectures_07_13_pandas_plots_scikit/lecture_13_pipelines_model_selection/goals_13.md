# Lecture 13: Model Pipeline

## Learning Goals

- Build scikit-learn Pipelines combining preprocessing, feature selection, and classification.
- Define hyperparameter grids and use GridSearchCV with cross-validation.
- Compare multiple models (RandomForest, KNN, SVM, LogisticRegression) on metrics and cost.
- Understand model selection workflow: metrics choice, cross-validation, stacking ensemble.
- Choose proper performance metrics (accuracy vs recall) based on use-case context.

## Files

- `lec_13a_simple_pipeline.ipynb` — Wine quality classification pipeline: 4 classifiers, GridSearchCV.
- `lec_13b_model_selection_stacking.ipynb` — Model selection on breast cancer data: cross-validation, comparison.
- `lec_13c_select_proper_performance_metric.ipynb` — Choosing the right metric: accuracy vs recall trade-off.
- `hyper_param_grids_pipelines.ipynb` — RandomForest pipeline with hyperparameter grid search.
- `model_selection.ipynb` — Earlier version of model selection with multiple classifiers.
- `plot_stack_predictors.ipynb` — Scikit-learn stacking example on Ames Housing data.
