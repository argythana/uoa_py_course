# Lecture 07: Pandas

## Learning Goals

- Open CSV files and load data into pandas DataFrames.
- Use basic DataFrame attributes and methods (`info()`, `head()`, `columns`, `dtypes`).
- Index and slice DataFrames using `.loc[]` and `.iloc[]`.
- Apply DataFrame methods: rename, replace, drop, conditional selection, `axis` parameter.
- Awareness of advanced data management modules (Polars, PySpark, Dask, DuckDB).

## Files

- `lec_07a_pandas_df_index_slice.ipynb` — Introduction to pandas: opening CSV, basic DataFrame info, indexing and slicing.
- `lec_07b_pandas_methods.ipynb` — Pandas methods: view vs modify, rename, replace, drop, conditional selection.
- `lec_07c_updated_informed_data_management_modules.ipynb` — Advanced optional: overview of Polars, PySpark, Dask, and others.
