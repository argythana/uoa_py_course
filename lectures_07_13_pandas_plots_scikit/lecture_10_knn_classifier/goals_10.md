# Lecture 10: KNN Classifier

## Learning Goals

- Understand KNN as a supervised, lazy-learning classification algorithm.
- Implement KNN classification using scikit-learn on the iris dataset.
- Understand key hyperparameters: K (`n_neighbors`), `weights`, distance metric, `leaf_size`.
- Visualize decision boundaries to understand classification regions.
- Use AI tools to study and deepen understanding of ML concepts.

## Files

- `lec_10a_knn.ipynb` — KNN classification tutorial: theory, iris EDA, scikit-learn implementation.
- `lec_10a_knn_iris_scikit.ipynb` — Alternative version using scikit-learn's data loading.
- `lec_10b_study_knn_use_AI.ipynb` — AI-assisted study: Q&A on lazy learning, KNN pros/cons.
- `lec_10c_knn_decision_boundaries.ipynb` — Decision boundary visualization with uniform vs distance weighting.
