# Lecture 12: Logistic Regression, Naive Bayes, SVM

Three supervised classifiers, contrasted on the **same kind of problem**: given a labelled training set, predict a discrete class label for a new observation. Two-thirds of the lecture is logistic regression — the workhorse, the one whose internals (sigmoid, log-odds, probit alternative, regularization) are easiest to read and the one whose vocabulary appears across the rest of the course. The remaining third covers Gaussian Naive Bayes and Support Vector Machines as **alternative model families with different assumptions**: NB for the conditional-independence regime where features are roughly independent given the class, and SVM for the margin-maximising regime where the decision boundary is geometrically clean.

Pipelines and `GridSearchCV` are **not** in this lecture — they are owned by Lecture 13. Where this lecture touches hyperparameters, it varies one parameter at a time on a fixed train/test split, the way `lec_10d` does for KNN.

### Required

- **G1.** State when **logistic regression** is the right tool: a supervised classification problem with a labelled training set, a small-to-medium number of features, where interpretable per-feature effects matter. Distinguish it from linear regression (continuous target → logit + sigmoid → probability → threshold → class). Name three industry uses (spam detection / disease screening / loan approval). *(file: `lec_12a_logistic_regression_intuition.ipynb` §B–D)*
- **G2.** Fit logistic regression with **three Python APIs** on the same dataset: `statsmodels.Logit` (stats summary table with p-values), `pingouin.logistic_regression` (tidy odds-ratio table), `sklearn.linear_model.LogisticRegression` (predict / `predict_proba` / `decision_function`). Explain *when to reach for which*. *(file: `lec_12b_logit_probit_values_predictions.ipynb` §C, §E, §F, §H)*
- **G3.** Read the four quantities a logistic-regression fit produces — **(a) the logit** (log-odds, linear predictor; `decision_function` in sklearn), **(b) the probit alternative** (the same model with the normal-CDF link, `statsmodels.Probit`), **(c) the predicted probability** (`predict_proba`), **(d) the predicted class** (`predict`, after thresholding at 0.5). Walk a single observation from features to class. *(file: `lec_12b` §C, §D, §F, §G)*
- **G4.** Fit and evaluate **Gaussian Naive Bayes** on a multi-class problem (iris). Read accuracy and the confusion matrix on a held-out test split. State the **conditional independence assumption** and give one example where it holds, one where it fails. Name the right NB variant for non-Gaussian data (`MultinomialNB`, `BernoulliNB`, `CategoricalNB`) without fitting them. *(file: `lec_12e_naive_bayes.ipynb` §B, §D, §E, §G, §H)*
- **G5.** Fit and evaluate an **SVM classifier** (`sklearn.svm.SVC`) on a 2D slice of iris so the decision boundary is visualisable. Contrast the **linear** and **RBF kernel** on the same axes. Explain in one sentence each what the hyperparameters **`C`** (regularization strength) and **`gamma`** (RBF kernel width) control, by varying one at a time on a fixed train/test split. State that SVM **requires feature scaling** before fitting. *(file: `lec_12f_SVM.ipynb` §B, §C, §D, §E, §F, §G)*
- **G6.** Across all three classifiers, distinguish the three model outputs: the **raw linear/decision value** (`decision_function`), the **probability** (`predict_proba` when available), the **class label** (`predict`). Identify which classifier exposes which output natively, which requires calibration (SVM with `probability=True`), and why this matters when downstream code asks for "the prediction". *(files: `lec_12b` §F, §G; `lec_12e` §E; `lec_12f` §H)*

Then fits `statsmodels.Probit` on the same data to show the probit-vs-logit link function contrast — both models give nearly identical predictions, but log-odds (logit) coefficients differ in scale from probit z-scores. Closes with a multi-class extension on iris (OVR vs multinomial in one consolidated cell). (~39 cells.)
- **`lec_12e_naive_bayes.ipynb`** — **Conditional independence and the GaussianNB workflow.** Iris → train/test split → `GaussianNB().fit().predict()` → accuracy + confusion matrix + classification report. The conditional-independence assumption explained on iris (feature pairs are clearly correlated → so why does NB work anyway?). The right NB variant for non-Gaussian data (`MultinomialNB` for word counts, `BernoulliNB` for binary features, `CategoricalNB` for categorical). The single hyperparameter `var_smoothing` (Laplace-style smoothing, varied one-at-a-time). (~37 cells.)
- **`lec_12f_SVM.ipynb`** — **Margin maximisation and the kernel choice.** Iris 2D slice (petal-length × petal-width) → `StandardScaler` (mandatory) → `SVC(kernel='linear')` and `SVC(kernel='rbf')` on the same axes with decision-boundary plots. Honest note: SVM scales O(n²)–O(n³) so it stops being practical past ~10 000 samples. (~28 cells.)
