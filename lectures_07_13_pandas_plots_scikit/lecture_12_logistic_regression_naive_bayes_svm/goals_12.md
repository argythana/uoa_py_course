# Lecture 12: Logistic Regression, Naive Bayes, SVM

## Learning Goals

- Implement logistic regression for binary and multi-class classification using scikit-learn, statsmodels, and pingouin.
- Understand the sigmoid function properties and probability interpretation.
- Implement Gaussian Naive Bayes classification; understand the conditional independence assumption.
- Implement SVM classification with Pipeline, scaling, feature selection, and GridSearchCV.
- Compare different supervised classification libraries and their use cases (stats vs predictions).

## Files

- `lec_12a_logistic_regression.ipynb` — Logistic regression: 3 libraries, 3 datasets, binary/multi-class.
- `lec_12b_naive_bayes.ipynb` — Gaussian Naive Bayes on iris: train/test split, confusion matrix.
- `lec_12c_SVM.ipynb` — SVM classification on wine dataset with Pipeline, GridSearchCV.
